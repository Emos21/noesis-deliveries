# Mumbi Salon, opening hours card

**Mumbi-Salon-Opening-Hours.pdf** is the card. One page, A4, ready to print.
Print it at 100 percent scale (not "fit to page") so the border stays even.

The other two files are only there if the hours ever change:

- **opening-hours.html** is the same card in editable form. Open it in a
  browser, edit the day or time you need, then print to PDF from the browser.
- **build_pdf.py** rebuilds the PDF from that HTML on a machine that has
  WeasyPrint installed. Run `python3 build_pdf.py` from this folder.

Hours currently on the card:

| Day | Hours |
| --- | --- |
| Monday to Friday | 9.00 am to 7.00 pm |
| Saturday | 9.00 am to 5.00 pm |
| Sunday | Closed |
